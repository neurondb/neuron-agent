# Support

- **Bug reports & features:** use [GitHub Issues](https://github.com/neurondb/neuron-agent/issues) with the appropriate template.
- **Security:** see [SECURITY.md](SECURITY.md) — do not file public security issues.
- **Hosted documentation:** [neurondb.ai — NeuronAgent](https://www.neurondb.ai/docs/neuronagent)

For deployment questions, include NeuronAgent version (`GET /version`), PostgreSQL version, and whether NeuronDB extensions are installed.
