# SQL / schema inspection

NeuronSQL tools are registered with the NeuronSQL module (e.g. `neuronsql.schema_snapshot`, `neuronsql.explain_json`). Create tools in the database with `handler_type` matching the registry or call HTTP routes under `/api/v1/neuronsql/*`.

See [NeuronSQL docs](../docs/neuronsql/quickstart.txt) and the main README API section.
