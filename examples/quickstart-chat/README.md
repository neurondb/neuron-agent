# Quickstart chat example

Prerequisites: running NeuronAgent + migrations + API key (`NEURON_AGENT_API_KEY`).

```bash
export NEURON_AGENT_API_KEY=your-key
export NEURON_AGENT_URL=http://127.0.0.1:8080
bash demo.sh
```

Creates a session and sends a hello message. Adjust `demo.sh` for your agent ID.
